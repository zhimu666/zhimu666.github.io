# SIGNAL · AI 行业日报

一个零依赖的 AI 行业日报看板。明亮浅色界面、蓝紫强调色与醒目的头条排版，适合桌面浏览和 B 站科技视频录屏，也支持手机阅读。

> 本项目是静态交互演示。九条新闻、关注指数与走势均为示例，不是实时新闻；顶部日期为设备本地日期。

## 功能

- 今日重点摘要、九条分级新闻和今日趋势面板。
- 一张头条大卡片 + 八张常规卡片，保留前三条新闻的主次层级。
- 按「全部 / 高优先级 / 中优先级」筛选，当前选择高亮。
- 九张卡片均可收藏（☆ / ★）或切换「阅读完成 / 已完成」，完成后右上角显示对勾。
- 搜索、优先级、分类、「只看未读」与「只看收藏」可以叠在一起用，互不覆盖。
- 阅读进度基于全部九条新闻统计；筛选不会重置阅读状态。
- 尝试通过 localStorage 保存阅读状态；浏览器禁用存储时，仍可在当前页面正常操作。
- 760px 及以下为单列布局，趋势面板移至新闻下方。
- 原生按钮支持键盘操作、焦点高亮和辅助技术状态播报。

## 打开网页

双击 `index.html`，使用 Edge、Chrome 或 Firefox 打开即可。无需安装依赖、构建项目、运行服务器或联网，也不需要管理员权限；文件夹继承当前项目的常规权限。

桌面录屏建议使用 1440 × 900 或 1920 × 1080 分辨率、100% 浏览器缩放。手机端可通过浏览器设备模拟查看。

## 交互与实现

新闻卡片通过 `data-priority` 声明重要程度，通过 `data-id` 维护稳定标识。筛选只修改卡片的 `hidden` 属性；阅读按钮只更新独立的完成集合，并同步按钮文字、`aria-pressed`、对勾与进度。这两个功能互不覆盖。

本地存储键为 `signal-ai-daily-read-v1`。不同浏览器对 `file://` 存储行为可能不同，持久化失败时会自动退回当前页面内状态。再次点击已完成按钮即可取消，无需清理存储。

## 阅读体验

- 默认使用明亮浅色主题，配合白色卡片、浅蓝背景、蓝紫强调色和更清晰的文字对比；仍可切换深色。
- 新版主题使用独立偏好键 `signal-ai-daily-theme-v2`，第一次打开新版为浅色，之后保留选择。
- 搜索标题、正文与分类，支持与分类、优先级、只看未读共同筛选。
- 「重置筛选」恢复全部新闻，不清除已读记录和详情展开状态。
- 显示当前结果数量与剩余未读数，全部读完后给出完成反馈。
- 在只看未读模式标记完成后，焦点移至下一条可见新闻；没有结果时移至重置按钮。

## 内容扩充

- 新闻从 3 条扩展到 9 条，覆盖大模型、AI 产品、行业动态、学术前沿四类。
- 分类与优先级共同筛选；阅读计数始终基于全部 9 条。原有三条新闻的本地阅读标识保持兼容。
- 3 组可切换排行榜，每组 5 项；5 条热度趋势；6 条按时间倒序排列的演示快讯。
- 所有新闻都有详情展开及独立阅读按钮。切换筛选、榜单和主题不重建新闻卡片，不丢失展开与阅读状态。
- 新闻为主题观察，榜单数值、变化及快讯时间均为演示数据，没有接入实时新闻服务。
- `rankingData` 集中维护排行榜；新闻和快讯位于 HTML 对应区域，可直接编辑。

## 第四轮：阅读效率与图表

这一轮由 Claude 协助重写 `index.html`，沿用原有的浅色蓝紫风格、九条新闻文字和全部原有功能，新增以下内容。

- **阅读进度环**：显示已读条数和按每条阅读时长估算的剩余分钟数（头条与第二条约 2 分钟，其余约 1 分钟）。
- **复制今日摘要**：把今天的高优先级标题和阅读进度复制成一段文字，方便发给别人。
- **键盘快捷键**：`/` 定位搜索，`j` / `k` 在新闻间移动，`r` 标记当前这条已读，`t` 切换主题，`?` 打开快捷键面板。
- **七日走势折线图**：三条话题曲线，鼠标悬停或聚焦后用方向键逐日查看，图下有数据表，不依赖颜色也能读数。配色（蓝、橙、青）用校验脚本检查过相邻色的区分度，深浅两套各自校验。
- **排行榜三组数据**：热点话题沿用原有五项，另外两组（模型方向、AI 产品方向）为新增的示例数据，均已标注。
- **搜索范围更准**：只搜索标题、分类、摘要与展开观察，不再匹配「阅读完成」这类按钮文字。
- **走势与排行数据集中**：`rankingData` 与 `trend` 两个对象都在脚本顶部，直接改数字即可。

### 兼容性说明

- 阅读状态改存到 `signal-ai-daily-read-v2`。原来的 `signal-ai-daily-read-v1` 没有迁移，第一次打开新版时阅读进度会从零开始。主题偏好键 `signal-ai-daily-theme-v2` 不变。
- 原版源码当时没有拿到，新版是依据线上页面上的文字重建的，新闻文字保持一致，布局与细节以新版为准。
- 走势的七日数值、两组新增排行榜的名称与指数均为示例数据，不是真实统计。

## 第五轮：收藏与分享元数据

这一轮继续沿用第四轮的结构，新增收藏，并把页面分享出去时的样子补齐。

- **收藏**：每张卡片右下角多了一个星标按钮，亮起表示已收藏。存储键是独立的 `signal-ai-daily-star-v1`，与阅读状态互不影响。
- **只看收藏**：筛选区新增一个勾选项，与「全部 / 高优先级 / 中优先级」、分类、搜索、「只看未读」叠加使用。在只看收藏的状态下取消收藏，焦点会自动移到下一条可见的新闻。
- **状态栏显示收藏数**：有收藏时，「还有 N 条未读」后面会多出「· 收藏 M 条」。
- **快捷键 `s`**：收藏或取消收藏当前聚焦的那条新闻，快捷键面板里也补上了这一行。
- **复制今日摘要带上收藏**：有收藏时，复制出来的文字末尾会多一段「我收藏的」列表。
- **分享元数据**：加入内联 SVG 图标（不产生额外请求）、`theme-color`，以及 Open Graph / Twitter 标签。把链接发到微信或 QQ 时，会按 `og:title` 和 `og:description` 显示标题与描述。
- **横向滚动的提示**：窄屏下顶栏导航和趋势数据表放不下时，右侧会淡出，提示后面还有内容。顶栏导航现在也会自动判断是否需要这个提示，而不是一律淡出。
- **进度环的读屏文本**：`aria-label` 会跟着读数更新，例如「今日阅读进度，已读 3 条，共 9 条」。

`og:url` 写的是当前线上地址，如果以后换域名，记得一起改掉。
