# 王忠毅 · 个人作品集

参照《VibeCoding 作品集教程》的五屏结构制作的个人作品集网站，纯 HTML/CSS/JS 单文件，零依赖、零构建。

## 五屏结构

1. **首屏 Hero** — 大标题（姓名）+ 副标题（学校/专业）+ 三个入口按钮
2. **个人介绍** — 头像占位 + 定位 + 数据亮点
3. **作品展示** — SIGNAL · AI 行业日报（可直接点开体验，位于 `works/ai-daily/`）
4. **个人优势** — 4 个能力卡片（均来自已有作品沉淀，非虚构）
5. **联系方式** — 电话与邮箱联系卡片

另含**简历屏**：与 `王忠毅_个人简历.docx` 内容一致，支持下载完整简历。凡简历中未确认的信息以"待补充"标注，未编造任何假数据。

## 文件结构

```text
个人网站/
├── index.html              # 作品集主页
├── 王忠毅_个人简历.docx      # 简历下载文件
├── works/
│   └── ai-daily/           # 作品：SIGNAL · AI 行业日报
│       ├── index.html
│       └── README.md
└── README.md
```

## 打开方式

双击 `index.html` 即可在浏览器中打开，无需安装依赖或启动服务器。860px 以下自动切换移动端布局。

## 部署（可选）

如需上线分享，可将整个文件夹拖到 Netlify Drop（app.netlify.com/drop），即可获得公开链接；也可使用静态托管服务（GitHub Pages / Vercel 等）。
