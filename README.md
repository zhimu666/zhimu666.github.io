# 王忠毅 · 个人作品集

在线地址：https://zhimu666.github.io/

## 内容
- `index.html`：作品集首页（单文件，零外部依赖）
- `works/ai-daily/`：SIGNAL · AI 行业日报（人机交互课程作品）
- `works/gpa/`：绩点计算器
- `works/focus/`：专注台（任务清单 + 番茄钟）
- `works/timetable/`：课表

## 说明
- 全部为原生 HTML / CSS / JavaScript，无构建步骤，双击即可本地打开。
- 日报中的新闻与趋势数据均为界面演示，不是实时新闻。
- 绩点、课表、专注台的数据只保存在使用者自己的浏览器里（localStorage）。
- 小工具由本人提出需求与测试，借助 AI 辅助开发。
- 设计参考：taste-skill、ui-ux-pro-max、shadcn 等设计规范（仅借鉴原则，页面为自行实现）。
